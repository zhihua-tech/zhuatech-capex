# 企业资本性支出管理系统企业能力

## 领域覆盖

- **投资规划**：维护年度投资方向、额度、类别和项目组合
- **项目立项**：登记商业理由、范围、里程碑、收益和责任人
- **预算控制**：执行预算申请、占用、释放、调剂和超支拦截
- **投资审批**：按金额、组织、类别和风险执行分级决策
- **采购关联**：关联采购申请、合同、订单、付款和供应商
- **项目执行**：跟踪进度、成本、承诺金额、现金流和风险
- **投资变更**：管理追加、范围、工期、收益变更和重新审批
- **验收与转固**：完成实物验收、结算、投资项目/责任中心拆分和会计转固
- **投后评价**：对比计划与实际收益、产能、节省和回收期

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业资本性支出管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ERP_PPM_FAM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
